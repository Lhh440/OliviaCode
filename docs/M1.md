# M1 · 真实工具闭环

> 目标：让模型真的碰到代码——能读、能改、能跑，改之前出 diff，出错能回滚。

## 验收结果

两条自检脚本，均针对本地测试网关（OpenAI 兼容，`deepseek-v4.1-flash`）实跑。

### `node apps/desktop/dist/selftest.cjs`（agent 层）

```
PASS  A1 读路径     tools=read_file  text="Demo Repo"
PASS  A2 写路径     tools=read_file,apply_patch,read_file
PASS  A2b 撤销      restored=true
PASS  A3 命令执行   tools=run_command  text="Node 版本是 v22.23.4。"
PASS  A4 事件日志   events=16 kinds=user.message,tool.call,assistant.message,turn.end,snapshot,file.changed

5/5 通过
```

### `electron scripts/ui-e2e.cjs`（界面层，无头）

```
read turn finished: true
approval bar: true
write turn finished: true
README after write: "# OliviaCode M1 测试仓库"
README after undo: "# Demo Repo"
undo ok: true
```

## 工具契约

| 工具 | 风险 | 审批 | 说明 |
| --- | --- | --- | --- |
| `list_dir` | read | 自动 | 忽略 node_modules/.git/dist，上限 4000 条 |
| `read_file` | read | 自动 | 带截断提示，最多 256KB |
| `search` | read | 自动 | 字面量检索，可按扩展名过滤 |
| `apply_patch` | write | 询问 | `old` 必须唯一命中，0 次或多次都报错并让模型重读 |
| `write_file` | write | 询问 | 新建或整文件重写 |
| `run_command` | exec | 询问 + 总开关 | 参数数组启动，不经 shell，默认 120s 超时 |
| `git_status` | read | 自动 | `--short --branch` |
| `git_diff` | read | 自动 | 可传 path 看单文件 |

## 权限模型

- 三档：`每次询问` / `自动放行`（写自动、命令仍问）/ `全部放行`。
- 读工具永远不问——否则一次任务要点几十下。
- 命令执行另有总开关，默认关闭，开启需要一次显式确认。
- 「始终允许」把 `tool + 目标` 写进 `<workspace>/.olivia/policy.json`：

```json
{
  "version": 1,
  "allow": ["run_command:npm test", "apply_patch:docs"]
}
```

## 事件日志

每个任务一份 `<userData>/sessions/<taskId>.jsonl`：

| 事件 | 用途 |
| --- | --- |
| `user.message` | 重放用户消息 |
| `assistant.message` | 重放助手消息（含工具卡与 diff 的最终状态） |
| `tool.call` | 审计：调了什么、参数、是否批准、结果摘要 |
| `file.changed` | 审计：改了哪个文件、增删行数 |
| `snapshot` | 审计：快照 id 与涉及文件 |
| `undo` | 审计：撤销了哪次快照 |
| `turn.start` / `turn.end` | 回合边界与失败原因 |

渲染层启动时调用 `olivia:task.load`，用 `replaySession` 重建消息；日志是权威来源，localStorage 只存任务索引。

## 快照

- 位置：`<userData>/snapshots/<taskId>/<snap_xxx>.json`。
- 内容：受影响文件的原始文本，`null` 表示写入前不存在（撤销时删除）。
- 单文件上限 2MB，二进制跳过。
- 恢复即还原，M1 只支持最近一次。

## 已知取舍

- 工具结果回给模型时最多 12000 字符，`run_command` 的 stdout 截到 8KB，避免上下文爆炸。
- 单轮最多 12 步；同一轮连续 3 次工具失败即停，防止死循环烧 token。
- 审批等待 5 分钟自动拒绝，避免回合永久挂起。
- 命令不经 shell，管道/重定向需要显式 `cmd /c` 或 `sh -c`——用一点便利换掉注入面。
- `apply_patch` 只做严格唯一替换，不做模糊匹配；宁可失败让模型重读，也不猜。
